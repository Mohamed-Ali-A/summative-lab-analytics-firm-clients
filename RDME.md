# Summative Lab – Analytics Firm Clients

## Project Overview

This project demonstrates three core data science workflows using Python:

- Natural Language Processing (NLP)
- Time Series Analysis
- Neural Networks

The project simulates real-world analytics tasks for an analytics consulting firm working with customer reviews and predictive modeling.

---

## Part 1: Natural Language Processing (NLP)

In this section, customer reviews are cleaned and analyzed to understand language patterns.

### Tasks Completed

- Text preprocessing
- Lowercase conversion
- URL removal
- Punctuation removal
- Tokenization
- Stopword removal
- Lemmatization
- Word frequency analysis
- Bigram analysis
- Data visualization

---

## Part 2: Time Series Analysis

Customer review activity is analyzed over time.

### Tasks Completed

- Timestamp conversion
- Monthly review count
- Monthly average rating
- Rolling average calculation
- Trend visualization

---

## Part 3: Neural Networks

A Multi-Layer Perceptron (MLP) was built using TensorFlow/Keras to classify customer ratings from review text.

### Tasks Completed

- TF-IDF text vectorization
- Train/test split
- Neural network implementation
- Model training
- Model evaluation
- Classification report
- Confusion matrix
